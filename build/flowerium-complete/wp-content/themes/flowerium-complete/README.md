# 🌸 Flowerium Complete - Полноценная тема WordPress для цветочного магазина

## 📦 Структура темы

```
flowerium-complete/
├── style.css                          # Главный файл стилей + информация о теме
├── functions.php                      # Основные функции темы
├── header.php                         # Шапка сайта
├── footer.php                         # Подвал сайта
├── front-page.php                     # Главная страница
├── page.php                           # Шаблон страниц
├── single.php                         # Шаблон записей
├── archive.php                        # Шаблон архивов
├── search.php                         # Поиск
├── 404.php                            # Страница 404
├── comments.php                       # Комментарии
├── assets/
│   ├── js/
│   │   └── main.js                    # Основной JavaScript
│   ├── css/                           # Дополнительные стили
│   └── images/                        # Изображения темы
├── template-parts/
│   └── cart-mini.php                  # Мини-корзина
├── woocommerce/
│   ├── archive-product.php            # Каталог товаров
│   ├── single-product.php             # Карточка товара
│   ├── cart.php                       # Корзина
│   └── checkout.php                   # Оформление заказа
├── page-templates/
│   ├── template-contacts.php          # Страница контактов
│   └── template-catalog.php           # Страница каталога
└── languages/
    └── flowerium-complete.pot         # Файл переводов
```

## 🚀 Установка

### Вариант 1: Через админ-панель WordPress
1. Скопируйте папку `flowerium-complete` в `/path/to/wordpress/wp-content/themes/`
2. Войдите в админ-панель WordPress
3. Перейдите в **Внешний вид → Темы**
4. Найдите тему "Flowerium Complete" и нажмите **Активировать**

### Вариант 2: ZIP-архивом
1. Заархивируйте папку `flowerium-complete` в ZIP-файл
2. В админ-панели WordPress перейдите в **Внешний вид → Темы → Добавить новую → Загрузить тему**
3. Выберите ZIP-файл и нажмите **Установить**
4. Активируйте тему

## ⚙️ Необходимые плагины

### Обязательные:
- **WooCommerce** - интернет-магазин, корзина, оформление заказов

## 🎨 Настройка темы

### 1. Базовая настройка
Перейдите в **Внешний вид → Настроить**:

#### Контакты
- Телефон
- Email
- Адрес
- Режим работы

#### Социальные сети
- Instagram
- ВКонтакте
- Telegram
- WhatsApp

#### Логотип
Загрузите логотип в разделе **Свойства сайта → Логотип**

### 2. Создание меню
1. Перейдите в **Внешний вид → Меню**
2. Создайте главное меню (расположение: "Главное меню")
3. Рекомендуемая структура:
   - Главная
   - Каталог
   - Доставка
   - О нас
   - Контакты

### 3. Создание страниц
Создайте следующие страницы:

| Название | Шаблон | Примечание |
|----------|--------|------------|
| Главная | Front Page | Автоматически |
| Каталог | Каталог | Template: Catalog |
| Доставка | Default | Добавьте информацию о доставке |
| О нас | Default | Информация о компании |
| Контакты | Контакты | Template: Contacts |
| Корзина | Auto (WooCommerce) | Создается автоматически |
| Оформление заказа | Auto (WooCommerce) | Создается автоматически |

### 4. Настройка WooCommerce

#### Общие настройки
1. Перейдите в **WooCommerce → Настройки**
2. Заполните данные магазина:
   - Адрес: Крым, ваш город
   - Валюта: RUB (₽)
   - Язык: Русский

#### Доставка
Настройте зоны доставки (**WooCommerce → Настройки → Доставка**):

**Зона 1: Симферополь**
- Бесплатная доставка от 3000 ₽
- Стоимость: 300 ₽ (менее 3000 ₽)
- Срок: 2-4 часа

**Зона 2: Южный берег Крыма** (Ялта, Алушта, Гурзуф)
- Стоимость: 500 ₽
- Срок: в день заказа

**Зона 3: Западный Крым** (Евпатория, Саки)
- Стоимость: 700 ₽
- Срок: 1-2 дня

**Зона 4: Восточный Крым** (Феодосия, Судак)
- Стоимость: 800 ₽
- Срок: 1-2 дня

#### Оплата
Включите нужные методы оплаты:
- Наличные при получении
- Банковская карта онлайн (ЮKassa, Robokassa, CloudPayments)
- SberPay

### 5. Добавление товаров

#### Категории товаров
Создайте категории (**Товары → Категории**):
- Розы
- Тюльпаны
- Хризантемы
- Авторские букеты
- Свадебные букеты
- Корзины и коробки
- Монобукеты
- Детские букеты

#### Товары
При создании товара заполните:
- Название
- Описание
- Цена
- Изображения (главное + галерея)
- Категория
- Теги (розы, красные, день рождения и т.д.)
- Наличие
- Артикул

## 🛒 Функционал корзины

### AJAX добавление в корзину
- Товары добавляются без перезагрузки страницы
- Модальное окно корзины открывается автоматически
- Обновление количества в реальном времени
- Удаление товаров одним кликом

### Оформление заказа
- Выбор даты доставки (не ранее следующего дня)
- Выбор временного слота:
  - Утро (9:00 - 12:00)
  - День (12:00 - 16:00)
  - Вечер (16:00 - 20:00)
- Информация о доставке сохраняется в заказе
