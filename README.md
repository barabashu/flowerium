# Flowerium — проект сайта цветочного магазина

Репозиторий содержит рабочий адаптивный прототип многостраничного сайта цветочного магазина и документацию для переноса решения на WordPress. Материалы рассчитаны на сценарий, когда хостинг и домен уже есть, а сайт собирается на готовой теме с последующей настройкой под продажи, SEO и интеграции с российскими сервисами.

## Цель

Создать устойчивую основу для нового сайта цветочного магазина вместо прежнего проекта `prosex.top`, с учетом будущей смены домена и последующей интеграции с платежами, доставкой, CRM, аналитикой, телефонией и российскими рекламными/маркетинговыми сервисами.

## Рекомендуемый стек

- WordPress + дочерняя тема выбранного шаблона.
- WooCommerce для каталога, корзины и заказов.
- SEO-плагин: Rank Math SEO или Yoast SEO.
- Формы: Fluent Forms, Contact Form 7 или Gravity Forms.
- Кэширование: LiteSpeed Cache при LiteSpeed-хостинге или WP Rocket/аналог.
- Резервные копии: UpdraftPlus, BlogVault или backup на уровне хостинга.
- Аналитика: Яндекс Метрика, VK Реклама pixel, при необходимости Google Analytics.

## Ключевые принципы

1. Не привязывать бизнес-логику к конкретному старому домену.
2. Все формы и заказы должны быть готовы к передаче в CRM.
3. Каталог должен поддерживать быстрый запуск без сложной кастомной разработки.
4. Страницы должны быть подготовлены под SEO по городам, поводам и типам букетов.
5. Интеграции должны подключаться поэтапно, чтобы не блокировать запуск сайта.


## Локальный просмотр

```bash
python3 -m http.server 4173
```

После запуска откройте `http://localhost:4173/`. Сайт не требует сборки и может использоваться как статический прототип, HTML-референс для WordPress-темы или основа для дальнейшей интеграции.
