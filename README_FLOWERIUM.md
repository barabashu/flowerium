# 🌸 Flowerium — WordPress тема для цветочных магазинов в Крыму

## ✅ Создана полностью рабочая тема WordPress

Я создал **полноценную тему WordPress** с полной интеграцией WooCommerce, которая решает вашу проблему "Таблица стилей не найдена".

## 📦 Что внутри

### Тема: `flowerium-shop` (17KB архив)
Расположение: `/workspace/flowerium-complete/wp-content/themes/flowerium-shop/`

**Файлы темы:**
| Файл | Описание |
|------|----------|
| `style.css` | Стили + мета-информация темы (обязательно для WordPress) |
| `functions.php` | Настройки, WooCommerce интеграция, поля доставки |
| `header.php` | Шапка с логотипом, меню, телефоном и корзиной |
| `footer.php` | Подвал с контактами и меню |
| `index.php` | Главная страница: Hero, категории, популярные товары |
| `page.php` | Шаблон для обычных страниц |
| `woocommerce.php` | Страница магазина с фильтрами и сортировкой |
| `assets/js/main.js` | Мобильное меню, AJAX корзина, анимации |
| `README.md` | Полная документация по установке и настройке |

## 🚀 Установка

### Способ 1: Копированием файлов
```bash
# Скопируйте папку темы в ваш WordPress
cp -r /workspace/flowerium-complete/wp-content/themes/flowerium-shop /path/to/wordpress/wp-content/themes/
```

Затем в админ-панели WordPress:
1. **Внешний вид → Темы**
2. Найдите **Flowerium Shop**
3. Нажмите **Активировать**

### Способ 2: Через архив
1. Распакуйте `flowerium-shop.tar.gz`
2. Загрузите папку `flowerium-shop` в `/wp-content/themes/`
3. Активируйте в админ-панели

## 🛠 Troubleshooting

### ❌ "Таблица стилей не найдена"
**Решение:** Используйте эту тему — файл `style.css` содержит обязательный заголовок темы WordPress.

### ❌ WooCommerce не отображается
**Решение:** Установите и активируйте плагин WooCommerce, пройдите мастер настройки.

### ❌ Корзина не обновляется
**Решение:** Проверьте консоль браузера (F12) на ошибки JS. Отключите кэш.

### ❌ Ошибка 404 на товарах
**Решение:** Настройки → Постоянные ссылки → Сохранить изменения.
