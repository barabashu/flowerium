# Контентная модель

## Категория товара

Поля:

- Название категории.
- SEO-заголовок.
- Meta description.
- Краткое описание для верхней части страницы.
- Полное описание для нижней части страницы.
- Баннер или изображение категории.
- FAQ для расширенного сниппета.

## Товар

Поля:

- Название.
- Артикул.
- Цена.
- Старая цена при акции.
- Основное фото.
- Галерея.
- Состав.
- Размер.
- Цветовая гамма.
- Повод.
- Наличие.
- Возможность срочной доставки.
- Текст открытки.
- Рекомендованные дополнения.

## Дополнительные товары

Примеры:

- Открытка.
- Топпер.
- Мягкая игрушка.
- Шоколад.
- Воздушные шары.
- Ваза.

## Блог и полезные статьи

Темы для первых публикаций:

- Как выбрать букет на день рождения.
- Какие цветы дольше стоят.
- Что написать в открытке.
- Как ухаживать за розами.
- Какие букеты подходят для коллеги.

## Микротексты интерфейса

Рекомендуемые формулировки:

- «Пришлем фото букета перед доставкой».
- «Состав может незначительно отличаться из-за сезонности цветов, но стиль и стоимость букета сохраняются».
- «Укажите дату и удобный интервал доставки при оформлении заказа».
- «Если нужен срочный букет, напишите нам в мессенджер».
