# Техническое задание для WordPress

## Базовая установка

1. Установить актуальную стабильную версию WordPress.
2. Включить HTTPS и автоматическое обновление сертификата.
3. Создать дочернюю тему, если планируются правки шаблонов или CSS.
4. Настроить человекопонятные URL: `/%category%/%postname%/` или `/%postname%/`.
5. Удалить демо-контент темы после настройки.

## Требования к теме

Тема должна поддерживать:

- WooCommerce.
- Адаптивную верстку.
- Быструю загрузку мобильной версии.
- Настраиваемую шапку с телефоном, мессенджерами и корзиной.
- Категории товаров и фильтры.
- Конструктор блоков без жесткой зависимости от одного платного плагина.
- Возможность добавлять кастомные поля товара.

## Роли пользователей

- Администратор: техническая настройка сайта.
- Менеджер магазина: обработка заказов и товаров.
- Контент-менеджер: страницы, блог, SEO-тексты.
- Флорист/оператор: просмотр заказов без доступа к критичным настройкам.

## Обязательные плагины

- WooCommerce — каталог, корзина, заказы.
- SEO-плагин — мета-теги, sitemap.xml, schema.org.
- Плагин форм — заявки, обратная связь, корпоративные запросы.
- SMTP-плагин — надежная отправка писем.
- Плагин кэша — оптимизация скорости.
- Плагин безопасности — ограничение попыток входа, 2FA, журнал активности.
- Плагин резервного копирования — регулярный backup.

## Настройки WooCommerce

- Валюта: российский рубль.
- Налоговые настройки: согласно выбранной юридической модели.
- Статусы заказов: новый, подтвержден, оплачен, в сборке, передан курьеру, выполнен, отменен.
- Поля заказа: имя получателя, телефон получателя, адрес, дата, интервал доставки, комментарий, текст открытки.
- Уведомления: email, Telegram/CRM, SMS при необходимости.

## Производительность

Целевые показатели:

- Главная страница до 2–3 секунд на мобильном соединении при включенном кэше.
- Изображения товаров в WebP/AVIF при поддержке хостинга.
- Lazy loading для изображений ниже первого экрана.
- Минимум тяжелых визуальных эффектов и сторонних скриптов.

## Безопасность

- Уникальные логины администраторов.
- Двухфакторная аутентификация для админов.
- Ограничение попыток входа.
- Регулярные обновления ядра, темы и плагинов.
- Резервные копии перед обновлениями.
- Доступ к админке только по HTTPS.
