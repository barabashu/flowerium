# Полная структура сайта цветочного магазина Flowerium (Крым)

## Общая информация

**Название:** Flowerium  
**Регион:** Крым (Симферополь, Ялта, Севастополь, Евпатория, Феодосия, Керчь)  
**Тип:** Многостраничный интернет-магазин с доставкой цветов  
**Платформа:** Статический HTML/CSS/JS + WordPress (готовность к переносу)

---

## Карта сайта (Sitemap)

### Основные страницы

1. **Главная** (`index.html`)
   - Оффер и кнопки действия
   - Популярные категории
   - Хиты продаж
   - Поводы для покупки
   - Условия доставки
   - Преимущества
   - Отзывы
   - FAQ
   - Контакты

2. **Каталог** (`pages/catalog.html`)
   - Категории товаров
   - Фильтры (цена, повод, цвет, срочность)
   - Сетка товаров

3. **Карточка товара** (шаблон для WooCommerce)
   - Фотографии
   - Цена и размеры
   - Состав букета
   - Опции (открытка, подарки)
   - Дата и время доставки
   - Кнопки «В корзину», «Купить в 1 клик»

4. **Корзина** (`pages/cart.html`) ✓ Создана
   - Список товаров
   - Изменение количества
   - Удаление товаров
   - Итоговая сумма
   - Переход к оформлению

5. **Оформление заказа** (`pages/checkout.html`) ✓ Создана
   - Данные получателя
   - Адрес доставки (города Крыма)
   - Дата и интервал доставки
   - Способ оплаты (карта, СБП, наличные, ссылка)
   - Текст открытки
   - Согласие на обработку ПДн

6. **Успешный заказ** (`pages/success.html`) ✓ Создана
   - Номер заказа
   - Информация о заказе
   - Следующие шаги
   - Контакты для связи

7. **Доставка и оплата** (`pages/delivery.html`)
   - Зоны доставки по Крыму
   - Стоимость доставки
   - Способы оплаты
   - Гарантия свежести

8. **О магазине** (`pages/about.html`)
   - История компании
   - Преимущества
   - Команда флористов

9. **Контакты** (`pages/contacts.html`)
   - Телефоны
   - Email
   - Адреса магазинов
   - Форма обратной связи
   - Карта

## Воронка продаж

```
┌─────────────────────────────────────────────────────────────┐
│                    ВОРОНКА ПРОДАЖ                          │
└─────────────────────────────────────────────────────────────┘

1. ПРИВЛЕЧЕНИЕ
   ├── Реклама: Яндекс.Директ, VK Реклама, таргетированная реклама
   ├── SEO: поисковый трафик по коммерческим запросам
   ├── Соцсети: Instagram*, VK, Telegram-канал
   └── Рефералы: рекомендации клиентов

2. ПЕРВИЧНЫЙ КОНТАКТ
   ├── Главная страница → оффер, преимущества, хиты
   ├── Каталог → фильтры, удобный поиск
   ├── Карточка товара → фото, описание, цена
   └── Мессенджеры → быстрый заказ через WhatsApp/Telegram

3. ДОБАВЛЕНИЕ В КОРЗИНУ
   ├── Кнопка «В корзину» на карточке товара
   ├── Уведомление о добавлении
   ├── Возможность продолжить покупки
   └── Счётчик товаров в шапке

4. ОФОРМЛЕНИЕ ЗАКАЗА
   ├── Корзина → проверка состава, изменение количества
   ├── Checkout → форма с полями:
   │   ├── Получатель (имя, телефон)
   │   ├── Адрес (город, улица, подъезд, этаж)
   │   ├── Дата и время доставки (интервалы)
   │   ├── Оплата (карта, СБП, наличные, ссылка)
   │   ├── Открытка (текст)
   │   └── Доп. опции (фото перед отправкой, не звонить)
   └── Согласие на обработку ПДн

5. ПОДТВЕРЖДЕНИЕ
   ├── Страница успеха → номер заказа, инструкция
   ├── Менеджер связывается в течение 15 минут
   ├── Проверка наличия цветов
   ├── Подтверждение адреса и времени
   └── Отправка фото букета клиенту

6. ДОСТАВКА И ОПЛАТА
   ├── Сборка букета флористом
   ├── Фото готового букета
   ├── Доставка курьером в интервал
   ├── Оплата (онлайн или при получении)
   └── Подтверждение вручения

7. ПОСЛЕПРОДАЖНОЕ ОБСЛУЖИВАНИЕ
   ├── SMS/email с благодарностью
   ├── Просьба оставить отзыв
   ├── Программа лояльности
   └── Повторные покупки (напоминания о датах)
```

## Технические компоненты

### Корзина (JavaScript + localStorage)

**Файлы:**
- `assets/js/cart.js` — логика корзины
- `assets/js/checkout.js` — обработка формы заказа
- `assets/js/success.js` — отображение успешного заказа

**Функционал:**
- Добавление товаров из каталога
- Хранение в localStorage
- Изменение количества
- Удаление товаров
- Подсчёт итогов (товары + доставка)
- Передача данных на страницу оформления

### Оформление заказа

**Поля формы:**
- Получатель: имя, телефон
- Адрес: город (выпадающий список), улица, подъезд, этаж, домофон
- Доставка: дата (календарь), интервал (утро/день/вечер/ночь)
- Плательщик: опция «совпадает с получателем»
- Оплата: карта, СБП, наличные, ссылка
- Дополнительно: текст открытки, чекбоксы

**Интеграции (для WordPress/WooCommerce):**
- ЮKassa, CloudPayments, Т-Банк Касса — онлайн-оплата
- СБП — быстрые платежи
- CRM (amoCRM, Битрикс24) — управление заказами
- Telegram — уведомления менеджерам
- Яндекс.Метрика — цели аналитики

## Метрики успеха

**Конверсия:**
- Посещение → Добавление в корзину: 8–12%
- Корзина → Заказ: 40–60%
- Общий CR: 3–5%

**Средний чек:** 3500–5000 ₽

**LTV (повторные покупки):** 25–35% клиентов возвращаются в течение 3 месяцев
