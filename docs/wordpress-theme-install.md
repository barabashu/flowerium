# Установка темы Flowerium в WordPress

## Почему была ошибка «Таблица стилей не найдена»

WordPress принимает ZIP как тему только если внутри архива есть папка темы, а в ней находится файл `style.css` с обязательным заголовком темы. Обычный HTML-прототип с `assets/css/styles.css` не считается WordPress-темой, поэтому WordPress показывает ошибку «Таблица стилей не найдена» или «Тема установлена, но является не полной».

## Где лежит готовая тема

Полноценная тема находится в папке:

```text
wordpress-theme/flowerium
```

В этой папке есть обязательные файлы:

- `style.css` — паспорт темы для WordPress.
- `index.php` — основной fallback-шаблон.
- `functions.php` — подключение стилей, скриптов, меню, поддержки WooCommerce и настроек.
- `header.php` и `footer.php` — общие части сайта.
- `front-page.php` — главная страница.
- `page-catalog.php`, `page-delivery.php`, `page-about.php`, `page-contacts.php` — шаблоны ключевых страниц.
- `woocommerce.php` — базовая обертка для WooCommerce.
- `screenshot.svg` — превью темы в админке.

## Как правильно упаковать ZIP

Находясь в корне репозитория, выполните:

```bash
cd wordpress-theme
zip -r flowerium.zip flowerium
```

Важно: в ZIP должна попасть папка `flowerium`, а не только её содержимое. Внутри архива путь к таблице стилей должен быть таким:

```text
flowerium/style.css
```

## Как установить

1. Откройте WordPress-админку.
2. Перейдите в «Внешний вид» → «Темы» → «Добавить новую» → «Загрузить тему».
3. Загрузите `wordpress-theme/flowerium.zip`.
4. Активируйте тему Flowerium.
5. В «Внешний вид» → «Меню» создайте главное меню и назначьте его в область «Главное меню».
6. Создайте страницы `catalog`, `delivery`, `about`, `contacts` и назначьте им соответствующие шаблоны страниц.
7. В «Настройки» → «Чтение» выберите статическую главную страницу, если нужно использовать страницу вместо `front-page.php`.

## WooCommerce

Тема уже объявляет поддержку WooCommerce. После установки WooCommerce можно использовать его для реального каталога, корзины, оплаты и заказов. Текущая страница `page-catalog.php` — стартовый витринный шаблон, который можно заменить WooCommerce-магазином после наполнения товаров.
