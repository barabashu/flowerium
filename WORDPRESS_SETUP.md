# WordPress темы для Flowerium

Созданы две версии WordPress тем для сети цветочных магазинов в Крыму:

## 📁 Структура проектов

### 1. `site-new/` - Полностью новая тема (Flowerium)
**Путь:** `/workspace/site-new/wp-content/themes/flowerium/`

Это полностью новая, профессиональная тема WordPress с нуля, которая включает:

#### Файлы темы:
- `style.css` - Стили с полной интеграцией WooCommerce и адаптивным дизайном
- `functions.php` - Все необходимые функции WordPress и WooCommerce
- `header.php` - Шапка с логотипом, меню, телефоном и корзиной
- `footer.php` - Подвал с навигацией и контактами
- `index.php` - Главная страница с hero-секцией, категориями и товарами
- `page.php` - Шаблон для страниц
- `single.php` - Шаблон для записей блога
- `archive.php` - Шаблон для архивов
- `search.php` - Страница результатов поиска
- `404.php` - Страница ошибки 404
- `archive-product.php` - Каталог товаров WooCommerce
- `single-product.php` - Страница отдельного товара
- `template-parts/content.php` - Часть шаблона для постов

#### Особенности:
- ✅ Полная интеграция с WooCommerce
- ✅ Адаптивный дизайн (mobile-first)
- ✅ Регионы виджетов (Sidebar, Footer, Shop Sidebar)
- ✅ Поддержка кастомного логотипа
- ✅ Google Fonts (Manrope)
- ✅ SEO-оптимизированная структура
- ✅ Перевод на русский язык
- ✅ Интеграция с Contact Form 7 / Fluent Forms
- ✅ Кастомные настройки темы

### 2. `site-fixed/` - Исправленная версия существующего макета
**Путь:** `/workspace/site-fixed/wp-content/themes/flowerium-theme/`

Это исправленная версия вашего текущего HTML-макета, преобразованная в тему WordPress:

#### Файлы темы:
- `style.css` - Импортирует оригинальные стили + WordPress-специфичные дополнения
- `functions.php` - Базовые функции WordPress
- `header.php` - Конвертированная шапка из HTML
- `footer.php` - Конвертированный подвал из HTML
- `index.php` - Главная страница с оригинальным дизайном
- `assets/css/styles.css` - Оригинальные стили из проекта
- `assets/js/main.js` - Оригинальный JavaScript
- `assets/img/` - Все изображения из оригинального проекта

#### Особенности:
- ✅ Сохраняет 100% оригинального дизайна
- ✅ Минимальные изменения в коде
- ✅ Быстрый перенос существующего макета
- ✅ Работает "как есть" с минимальной настройкой

## 🚀 Установка

### Вариант A: Через админ-панель WordPress

1. **Упакуйте тему в ZIP:**
   ```bash
   # Для новой темы
   cd /workspace/site-new/wp-content/themes
   zip -r flowerium.zip flowerium/
   
   # Для исправленной темы
   cd /workspace/site-fixed/wp-content/themes
   zip -r flowerium-theme.zip flowerium-theme/
   ```

2. **Загрузите в WordPress:**
   - Войдите в админ-панель WordPress
   - Перейдите: Внешний вид → Темы → Добавить новую → Загрузить тему
   - Выберите ZIP-файл
   - Нажмите "Установить" → "Активировать"

### Вариант B: Через FTP/SFTP

1. Скопируйте папку темы (`flowerium` или `flowerium-theme`) в:
   ```
   /path/to/wordpress/wp-content/themes/
   ```

2. Активируйте тему в админ-панели:
   - Внешний вид → Темы
   - Найдите "Flowerium" или "Flowerium Theme (Fixed)"
   - Нажмите "Активировать"

Для полноценной работы установите следующие плагины:

### Обязательные:
- **WooCommerce** - каталог товаров, корзина, заказы
- **Contact Form 7** или **Fluent Forms** - формы обратной связи

### Рекомендуемые:
- **Yoast SEO** или **Rank Math** - SEO-оптимизация
- **WP Rocket** или **W3 Total Cache** - кэширование
- **Wordfence Security** - безопасность
- **UpdraftPlus** - резервное копирование
- **Advanced Custom Fields (ACF)** - дополнительные поля для товаров

| Характеристика | site-new (Flowerium) | site-fixed (Flowerium Theme) |
|----------------|---------------------|------------------------------|
| **Подход** | Новая разработка с нуля | Конвертация существующего HTML |

## 💡 Рекомендации

**Используйте `site-new`, если:**
- Хотите максимально функциональный сайт
- Планируете развивать проект
- Важна полная интеграция с WooCommerce
- Готовы потратить время на настройку

**Используйте `site-fixed`, если:**
- Нужно быстро запустить сайт
- Хотите сохранить текущий дизайн без изменений
- Минимальные требования к функционалу
- Планируете постепенную модернизацию

## 📞 Поддержка

При возникновении проблем:
1. Проверьте версию WordPress (требуется 6.0+)
2. Убедитесь, что PHP версии 7.4 или выше
3. Включите отладку в `wp-config.php`:
   ```php
   define('WP_DEBUG', true);
   define('WP_DEBUG_LOG', true);
   ```
4. Проверьте логи ошибок в `/wp-content/debug.log`
