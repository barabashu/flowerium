# Flowerium - Полноценная тема WordPress для цветочного магазина

## 📦 Структура темы

```
flowerium-theme/
├── style.css                 # Основные стили + мета-информация темы
├── functions.php             # Функции и настройки темы
├── header.php                # Шапка сайта
├── footer.php                # Подвал сайта
├── index.php                 # Главный шаблон
├── front-page.php            # Главная страница
├── single.php                # Страница поста
├── page.php                  # Страница
├── archive.php               # Архив
├── search.php                # Поиск
├── searchform.php            # Форма поиска
├── 404.php                   # Страница 404
├── sidebar.php               # Боковая панель
├── js/
│   └── main.js               # JavaScript функции
├── template-parts/
│   ├── content.php           # Шаблон контента поста
│   └── content-none.php      # Шаблон "ничего не найдено"
└── woocommerce/
    ├── content-product.php   # Карточка товара
    └── single-product.php    # Страница товара
```

## 🚀 Установка на TimeWeb

### Шаг 1: Подготовка архива
1. Создайте ZIP-архив из папки `flowerium-theme`
2. Название архива: `flowerium-theme.zip`

### Шаг 2: Загрузка в WordPress
1. Зайдите в админку WordPress: `ваш-сайт.ru/wp-admin`
2. Перейдите: **Внешний вид → Темы → Добавить новую**
3. Нажмите **Загрузить тему**
4. Выберите файл `flowerium-theme.zip`
5. Нажмите **Установить**, затем **Активировать**

### Шаг 3: Обязательные плагины

#### 3.1 WooCommerce (магазин)
1. **Плагины → Добавить новый**
2. Найдите **WooCommerce**
3. Установите и активируйте
4. Пройдите мастер настройки:
   - Адрес магазина: Крым, ваш город
   - Валюта: Российский рубль (₽)
   - Типы товаров: Физические товары
   - Оплата: Настройте позже
   - Доставка: Зоны доставки по городам Крыма

#### 3.2 Elementor (визуальный редактор) - опционально
1. **Плагины → Добавить новый**
2. Найдите **Elementor**
3. Установите и активируйте

#### 3.3 Contact Form 7 (формы)
1. **Плагины → Добавить новый**
2. Найдите **Contact Form 7**
3. Установите и активируйте

#### 3.4 Yoast SEO (SEO-оптимизация)
1. **Плагины → Добавить новый**
2. Найдите **Yoast SEO**
3. Установите и активируйте

### Шаг 4: Настройка темы

#### 4.1 Меню
1. **Внешний вид → Меню**
2. Создайте новое меню "Главное"
3. Добавьте страницы: Главная, Каталог, О нас, Доставка, Контакты
4. Выберите расположение: **Primary Menu**
5. Сохраните

#### 4.2 Виджеты подвала
1. **Внешний вид → Виджеты**
2. Добавьте в Footer Widget 1: Текст "О нас"
3. Добавьте в Footer Widget 2: Текст "Контакты"
4. Добавьте в Footer Widget 3: Меню "Footer Menu"

#### 4.3 Логотип
1. **Внешний вид → Настроить**
2. **Свойства сайта → Логотип**
3. Загрузите логотип (рекомендуемый размер: 400x100px)

#### 4.4 Настройка WooCommerce

##### Товары
1. **Товары → Добавить новый**
2. Заполните:
   - Название букета
   - Описание
   - Цена
   - Изображение товара (800x800px)
   - Категории (Розы, Тюльпаны, Сборные и т.д.)

##### Категории товаров
1. **Товары → Категории**
2. Создайте категории:
   - Розы
   - Тюльпаны
   - Хризантемы
   - Сборные букеты
   - Корзины с цветами
   - Монобукеты

##### Настройки доставки
1. **WooCommerce → Настройки → Доставка**
2. Добавьте зоны доставки:
   - Симферополь
   - Ялта
   - Севастополь
   - Евпатория
   - Феодосия
   - Керчь
3. Для каждой зоны добавьте методы:
   - Бесплатная доставка (от 5000₽)
   - Фиксированная стоимость (300₽)
   - Самовывоз (бесплатно)

##### Настройки оплаты
1. **WooCommerce → Настройки → Платежи**
2. Включите методы:
   - Прямой банковский перевод
   - Оплата при доставке (наличные)
   - ЮKassa (требуется отдельный плагин)
   - Сбербанк Онлайн (требуется отдельный плагин)

### Шаг 5: Создание страниц

#### Обязательно создайте:
1. **Главная** (назначьте как статическую главную)
2. **Каталог** (автоматически создаётся WooCommerce)
3. **О нас**
4. **Доставка и оплата**
5. **Контакты**
6. **Политика конфиденциальности**

#### Настройка главной страницы:
1. **Настройки → Чтение**
2. Выберите: **Статическая страница**
3. Главная страница: **Главная**
4. Страница записей: **Блог** (создайте отдельно)

### Шаг 6: Дополнительная настройка

#### Цветовая схема
Тема использует следующие цвета (можно изменить в style.css):
- Основной: #e91e63 (розовый)
- Тёмный: #c2185b
- Светлый: #f8bbd9
- Акцент: #4caf50 (зелёный)
- Текст: #2c3e50

#### Города доставки
В теме уже настроены поля для выбора города:
- Симферополь
- Ялта
- Севастополь
- Евпатория
- Феодосия
- Керчь

#### Время доставки
Поля выбора времени:
- Утро (9:00 - 12:00)
- День (12:00 - 17:00)
- Вечер (17:00 - 21:00)
- Любое время

## 🔧 Технические требования

- WordPress: 5.8+
- PHP: 7.4+
- MySQL: 5.6+
- WooCommerce: 6.0+
- Память PHP: 256MB+

## 📱 Адаптивность

Тема полностью адаптивна и корректно отображается на:
- Десктопах (1920px+)
- Ноутбуках (1200px - 1919px)
- Планшетах (768px - 1199px)
- Мобильных (320px - 767px)

## 🎯 Особенности темы

1. **Интеграция с WooCommerce** - полная поддержка интернет-магазина
2. **Адаптивный дизайн** - корректное отображение на всех устройствах
3. **SEO-оптимизация** - правильная семантическая разметка
4. **Быстрая загрузка** - оптимизированный код
5. **Русская локализация** - все тексты на русском языке
6. **Города Крыма** - предзаполненные поля доставки
7. **Мобильное меню** - удобное меню для смартфонов
8. **Корзина AJAX** - обновление без перезагрузки

## 📞 Контакты для поддержки

При возникновении проблем:
1. Проверьте консоль браузера (F12) на ошибки
2. Отключите плагины по одному для поиска конфликта
3. Включите отладку WordPress в wp-config.php
