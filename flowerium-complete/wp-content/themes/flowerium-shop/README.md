# Flowerium Shop — Полная WordPress тема для цветочного магазина

## ✅ Готовая к установке тема

Тема полностью готова к работе с WooCommerce и включает:

### 📁 Структура темы
```
flowerium-shop/
├── style.css              # Стили + мета-информация темы
├── functions.php          # Настройки, WooCommerce интеграция
├── header.php             # Шапка с меню и корзиной
├── footer.php             # Подвал с контактами
├── index.php              # Главная страница (Hero + Категории + Товары)
├── page.php               # Шаблон страниц
├── woocommerce.php        # Страница магазина с фильтрами
├── assets/
│   ├── css/               # Дополнительные стили
│   ├── js/
│   │   └── main.js        # Мобильное меню, анимации, AJAX корзина
│   └── img/               # Изображения темы
└── template-parts/        # Части шаблонов
```

## 🚀 Установка

### Вариант 1: Через админ-панель WordPress
1. Скопируйте папку `flowerium-shop` в `/path/to/wordpress/wp-content/themes/`
2. В админ-панели перейдите: **Внешний вид → Темы**
3. Найдите тему **Flowerium Shop** и нажмите **Активировать**

### Вариант 2: ZIP-архивом
1. Заархивируйте папку `flowerium-shop` в `flowerium-shop.zip`
2. В админ-панели: **Внешний вид → Темы → Добавить новую → Загрузить тему**
3. Выберите архив и нажмите **Установить**, затем **Активировать**

## 🛒 Настройка WooCommerce

### 1. Базовые настройки
```
WooCommerce → Настройки:
- Страна: Россия
- Регион: Крым
- Валюта: Российский рубль (₽)
- Единицы: кг, см
```

### 2. Доставка
```
WooCommerce → Настройки → Доставка:
1. Зоны доставки:
   - Симферополь (бесплатно от 5000₽)
   - Ялта, Алушта, Евпатория (500₽)
   - Остальной Крым (800₽)
   
2. Способы:
   - Курьерская доставка
   - Самовывоз из магазина
   - Срочная доставка (60 мин)
```

### 3. Оплата
```
WooCommerce → Настройки → Платежи:
- Наличные при получении
- Банковская карта (ЮKassa/Robokassa)
- Сбербанк Онлайн
```

### 4. Товары
```
Продукты → Добавить новый:
- Название букета
- Цена (обычная и акционная)
- Категория (Розы, Сборные, Коробки и т.д.)
- Изображения (главное + галерея)
- Описание состава и размеров
- Возможность пометить как "Хит"
```

## 🔧 Функции темы

### Интеграция WooCommerce:
- ✅ Собственная обёртка для товаров
- ✅ Кастомные хлебные крошки
- ✅ AJAX обновление корзины в шапке

- Анимация появления/исчезновения

## 🛠 Troubleshooting

### Тема не отображается?
- Проверьте наличие `style.css` с заголовком
- Права доступа: 755 для папок, 644 для файлов

### WooCommerce не работает?
- Установите и активируйте плагин WooCommerce
- Пройдите мастер настройки

### Корзина не обновляется?
- Проверьте, что JS загружается (Console в браузере)
- Отключите кэш на время разработки

### Ошибка 404 на странице товара?
- Пересохраните постоянные ссылки: **Настройки → Постоянные ссылки → Сохранить**
